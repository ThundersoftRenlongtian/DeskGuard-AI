DeskGuard AI

AI Agent 桌面健康教练 · 本地实现方案书

一、项目目标

在 Windows 电脑上实现一个可运行的 Demo：
PC 摄像头实时检测坐姿 → AI Agent 智能决策 → 桌面弹窗 + 灯光提醒

四、坐姿分类算法

使用 MediaPipe Pose 的 33 个关键点，计算关键角度进行坐姿判断：

检测项使用关键点判断方法阈值
驼背耳朵 → 肩膀 → 髋部三点连线角度< 155°
前倾肩膀中点 vs 髋部中点水平位移比> 设定值
低头鼻子 → 肩膀中点垂直俯角> 20°
歪坐左肩 vs 右肩Y 坐标高度差> 5%

5.3 Agent System Prompt

你是 DeskGuard AI 健康教练。

你的职责：
1. 根据用户坐姿数据，决定是否需要提醒
2. 选择合适的提醒方式和内容
3. 生成温和、有用的建议

决策原则：
- 不要过于频繁打扰用户
- 提醒内容要具体（"肩膀前倾了5°"比"注意坐姿"好）
- 鼓励为主，不制造焦虑
- 如果用户刚被提醒过，除非情况恶化，不要重复提醒

六、开发步骤

1

环境搭建 + 摄像头采集

安装 mediapipe、opencv-python，打开摄像头显示骨骼关键点

2

坐姿分类算法

状态机 + 触发逻辑

5

输出执行

6

集成测试 + 演示

完整链路测试，录制演示视频

七、项目文件结构

八、配置参数

# config.py
DEEPSEEK_API_KEY = "sk-xxx"           # platform.deepseek.com 获取
DEEPSEEK_BASE_URL = "https://api.deepseek.com"
DEEPSEEK_MODEL = "deepseek-chat"

# 坐姿阈值
SLOUCH_ANGLE_THRESHOLD = 155          # 肩部角度 < 此值 = 驼背
HEAD_DOWN_THRESHOLD = 20              # 头部俯角 > 此值 = 低头
SHOULDER_TILT_THRESHOLD = 0.05        # 左右肩高差比

# 提醒策略
POSTURE_ALERT_SECONDS = 60            # 不良坐姿60秒触发
SIT_DURATION_MINUTES = 45             # 久坐45分钟触发
COOLDOWN_MINUTES = 10                 # 提醒冷却

九、如何运行

cd deskguard-demo
pip install -r requirements.txt
python main.py

启动后会打开摄像头窗口，实时显示骨骼点和坐姿状态。当检测到问题并触发提醒时，会弹出 Windows 系统通知。
